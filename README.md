 # Seattle Libraries & Parks Tile Map

## Live Map
https://meronwb.github.io/tiles-qgis-map/ 

## Study Area
The study area for this project is Seattle, Washington. This map focuses on the spatial distribution of public libraries and parks, highlighting access to community resources and green spaces across the city.

## Tile Sets

### Tile Set 1: Basemap
This tile set is a custom basemap designed to provide geographic context for Seattle. It uses a simple olor scheme to show roads, water, and urban areas while keeping the design clean and easy to read.

### Tile Set 2: Thematic Layer
This tile set shows the distribution of libraries and parks in Seattle. It highlights where these resources are located and helps identify areas with more or fewer public amenities.

### Tile Set 3: Combined Map
This tile set combines the basemap and the thematic layer. It provides both geographic context and data, making it easier to understand how libraries and parks are distributed across the city.

### Tile Set 4: Theme Map
This tile set is designed with a community and environment theme. It uses color and style to emphasize the connection between libraries as learning spaces and parks as green spaces.

## Zoom Levels
Basemap: 10–13  
Thematic Layer: 10–13  
Combined Map: 10–13  
Theme Map: 10–13  


## Technologies Used
QGIS (tile generation)  
Mapbox GL JS (web map)  
GitHub Pages (hosting)

## Notes
This project demonstrates how raster tile sets can be created from geospatial data and displayed in an interactive web map using Mapbox GL JS. The layer switcher allows users to explore different map designs and compare basemaps and thematic layers.
